
# Windows Server 2022 Home Lab

## Project Overview

I built this home lab using VMware Workstation to gain hands-on experience with Windows Server administration, Active Directory, file sharing, and Group Policy.

The goal was to practice tasks commonly performed by IT Help Desk technicians and system administrators.

## Lab Environment

- Windows Server 2022
- Windows Client Virtual Machine
- VMware Workstation
- Active Directory Domain Services (AD DS)
- Group Policy Management
- File Server Resource Manager (FSRM)

## Tasks Completed

### 1. Active Directory Configuration
- Configured Active Directory Domain Services.
- Created and managed domain user accounts.
- Organized users through Active Directory.

### 2. Domain and Client Management
- Joined a Windows client to the domain.
- Logged in using domain user credentials.
- Practiced domain-based user administration.

### 3. File Sharing and Permissions
- Configured shared folders.
- Mapped network drives on the client computer.
- Configured file quotas using FSRM.
- Implemented file screening to restrict selected file types.

### 4. Security and Group Policy
- Configured account lockout policies.
- Practiced password and account security management.
- Configured user rights through Group Policy.

## Skills Gained

- Windows Server Administration
- Active Directory Management
- Domain User Management
- Network Drive Mapping
- File Server Management
- Group Policy Configuration
- Technical Troubleshooting
- IT Documentation
